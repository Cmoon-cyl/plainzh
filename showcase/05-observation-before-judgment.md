# 分清取得证据与作出判断

[← 返回案例索引](README.md)

来源类型：能力评估报告。场景、取证动作和工具分工挤在同一段，前后依赖不够醒目。

## 改写前

再换成“勾选以后刷新页面，选中状态仍被保存”，只读最终回复无法验证。必须实际操作页面、观察刷新与存储故障，取得结果后才能判断。决策模型并不替代这一步取证。一次完整评测可能同时调用程序、决策模型和能执行工具的 Agent，划分依据是每个检查单元需要什么证据。

## 改写后

要求是“勾选以后刷新页面，选中状态仍被保存”时，仅阅读最终回复无法验证。必须实际操作页面，观察刷新和存储故障时的行为，再根据证据判断。决策模型不能替代取证。

因此，一次完整评测可以同时使用程序、决策模型和能执行工具的 Agent。具体分工取决于每个检查单元需要的证据和判断方式。

## 改了什么

先完整说明页面行为需要怎样验证，再用独立段落解释程序、决策模型与工具 Agent 的分工。

**保留的含义：** 只读最终回复无法验证页面状态；必须实际操作并观察；决策模型不能代替取证。

**脱敏说明：** 具体模型名替换为“决策模型”。页面场景不含站点、用户、地址或实际测试结果。
